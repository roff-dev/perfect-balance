# Perfect Balance

A daily 3D balance-scale game. You get a thing on one pan, say an elephant, and a pile of everyday objects to stack on the other until you think the weights match. Then the scale lets go.

## Running it locally

```sh
npm install
npm run dev
```

## Built with

three.js, Jolt Physics (in a Web Worker), camera-controls, Svelte and Vite. Type is Fraunces and Instrument Sans, both under the SIL Open Font License.
